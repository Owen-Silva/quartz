# Brave logo (attribution on search.html)

Brave's own files, unchanged, shipped with Quartz so the results page never hotlinks them.

| File here | Brave's file | For |
| --- | --- | --- |
| brave-logo-on-dark.svg | https://brave.com/static-assets/images/brave-logo.svg (light "brave" wordmark) | dark theme |
| brave-logo-on-light.svg | https://brave.com/static-assets/images/brave-logo-dark.svg (dark "brave" wordmark) | light theme |

Both are the logo shown on Brave's brand page, https://brave.com/brave-branding-assets/ , whose
download is the Brave Logo Package (https://brave.com/static-assets/files/BrandBrave.zip:
Brave-Logos/light background + dark background, the same lion-and-wordmark lockup as PNG/AI/EPS).
The SVGs are used because the PNGs are 3063 x 950 and the page shows the logo about 14 px tall.

The rule they serve: Brave Search API Terms of Service, section 4(d) "Attribution"
(https://api-dashboard.search.brave.com/terms-of-service): attribution is optional, but if given it
must be conspicuous and "consist of the language "POWERED BY BRAVE" plus Provider's logo". Quartz
gives it, so the page shows both. No partnership or endorsement may be implied.
